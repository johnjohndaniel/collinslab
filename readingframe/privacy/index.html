Reading Frame

Privacy policy

Last updated 8 November 2026.

What this application is

Reading Frame is a personal, single-user tool. It turns research papers into short explainer videos and uploads them to its owner's own YouTube channel. It is not a product offered to other people, it has no accounts, and it has no users other than its owner.

Google user data it accesses

When its owner signs in with Google, the application requests two scopes:

  • youtube.upload — to upload video files to the owner's own YouTube channel.
  • youtube.readonly — to read back the channel name and the status of a video it has just uploaded, so the upload can be confirmed.

It requests no other Google data. It does not read email, files, contacts or calendars, and it does not access any account other than the one that grants it access.

How that data is used and stored

  • The OAuth token is stored only on the owner's own computer, in a private directory readable by the owner alone. It is never transmitted anywhere except to Google.
  • Video files, titles and descriptions are sent to YouTube in order to publish them.
  • No Google user data is sold, shared with third parties, used for advertising, or used to train any machine-learning model.
  • No analytics, tracking or cookies are used by this application, and this page sets none.

Retention and removal

The stored token is kept until it is deleted or revoked. Access can be withdrawn at any time from the Google Account permissions page at myaccount.google.com/permissions, which immediately and permanently ends the application's access. Deleting the local token file has the same effect on this side.

YouTube API Services

This application uses YouTube API Services. By using it you are agreeing to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Content and corrections

Videos published by this project summarise published research and reproduce figures from the papers they discuss for the purposes of commentary and education, with the source paper and its DOI cited in every video. Narration is produced with a synthetic voice; no video contains a recording of a real person. If something is inaccurate, or if you are an author who would like a video corrected or taken down, write to the contact address below and it will be acted on.
